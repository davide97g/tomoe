# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, welcome newcomers, disagree about ideas and never about people. Harassment of any kind is not tolerated.

To report a problem, use GitHub's private reporting on this repository (Security tab), or contact the maintainers through their GitHub profiles. Reports are handled confidentially.
